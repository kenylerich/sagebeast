# 路线图

阶段按依赖排列。前一阶段没有接受记录时，不开始后一阶段的实现。

## 阶段 0：需求管理

状态：进行中，本仓库当前只做这一阶段。

交付物是文档、Issue 模板、标签、PR 策略、生命周期和编码门禁。没有产品行为。

完成标准：远端仓库能用模板开 Issue，PR 检查能拒绝缺少 Issue 引用或标签的人类 PR，门禁能拒绝产品目录。

## 阶段 1：只读研究基线

依赖：REQ-001、REQ-002、REQ-003、REQ-004 被接受，且 Q1 和 Q3 有结论。

交付物是一个只能读取行情和公开研究字段的 Agent 会话。它能说明每次数据调用，不能触发回测，不能写扩展表，不能交易。

## 阶段 2：跑分契约

依赖：阶段 1 的读取路径可用，REQ-005 被接受，Q4 有结论。

交付物是一组固定研究任务、评分规则和可重复运行的记录。分数衡量研究行为是否遵守任务和数据证据，不衡量收益。

## 阶段 3：自优化循环

依赖：阶段 2 的评分能独立复跑，REQ-006 和 REQ-008 被接受，Q2 有结论。

交付物是 Propose–Probe–Compose 循环和经验库。验收看同一任务集上的分数变化和实验可复现，不看一次偶然的好答案。

## 不在路线图里

- 实盘下单。
- 荐股或涨停预测。
- 自建数据源。
- 移植 Harness² 的外部基准。
- 在需求未接受时预写上述实现。
