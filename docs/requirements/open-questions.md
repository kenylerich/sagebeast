## Q1. Sagebeast 怎样装入 DeepSeek Harness

挡住：REQ-002。

建议：本仓库发布一个插件包和 preset，由本机 `dsh` 装载。不 fork 上游，也不在本仓库重写启动器。

仍需确认：包名、profile 名称，以及开发时指向 `/Users/kenyle/workspace/agent/deepseek-harness` 的方式。子模块、`npm link` 和已发布版本是三种不同的开发体验，现在不选。

## Q2. 自优化循环由谁驱动

挡住：REQ-006。

建议：先定义任务、候选 harness 和评分结果的文件契约。驱动器可以是仓外命令，也可以是 `dsh` workflow。无论哪一种，执行会话都必须是 DeepSeek Harness，而不是 Harness² 的 OpenCode 或 Codex substrate。

仍需确认：并行探测的并发上限，以及失败探测是否消耗预算 `k`。

## Q3. 库代码和会话分别怎样取数

挡住：REQ-003、REQ-007。

建议：可测试的库代码调用 Open API。交互式会话可以挂 tick-stock-panel MCP。两条路都使用同一个 Bearer Token 和同一组 scope，MCP 不拥有额外业务逻辑。

仍需确认：开发环境的 `TSP_BASE` 默认值，以及 Token 存在 Harness 凭据还是进程环境。Token 不能进 Git。
