## REQ-001 固定三平面边界

问题：后续实现若直接调用数据源、重写 Agent 循环或换执行器，分数和数据口径都无法解释。

可观察结果：每份实现 PR 能指出所改平面。越界改动在审查时被拒绝。

验收：

- [架构](../architecture.md) 和 [边界](../boundaries.md) 与 [0001](../decisions/0001-three-plane-architecture.md) 一致。
- 新增产品路径的 PR 模板包含 Runtime、Data、Optimize、Safety 四项，没有影响时写 None。

非目标：不在本条选择包管理器或进程模型。

## REQ-002 消费 DeepSeek Harness

问题：股票 Agent 需要会话、工具、审批和 MCP，这些已经在 DeepSeek Harness 里。

可观察结果：研究者通过本机 `dsh` 进入 Sagebeast preset 或插件，而不是启动另一个 Agent 运行时。

验收：

- 启动路径调用 `dsh`，不复制 agent loop。
- 卸载插件后，Sagebeast 注册的工具和提示片段消失。
- 开发文档写明所用 `dsh` 版本或检出提交。

非目标：不修改 `/Users/kenyle/workspace/agent/deepseek-harness` 的核心包来迁就本项目。

## REQ-003 只经 tick-stock-panel 取数

问题：自建数据客户端会分裂复权、交易日和单位口径。

可观察结果：所有行情和研究字段都来自 tick-stock-panel 网关响应。日志能看到端点、scope 和数据时间。

验收：

- 默认 Token 只有读取所需 scope。没有 `paper:trade` 和 `admin`。
- 网关 401、403、429 和缺字段时，调用失败并保留错误正文。
- 仓库里没有厂商 SDK、Parquet 读取器或单位启发式转换。
- 测试使用录制的网关响应或本地假网关，不依赖生产 Token。

非目标：不重新实现 MCP 服务器。会话若使用 MCP，使用 tick-stock-panel 自带的薄桥。

## REQ-004 研究输出的安全边界

问题：研究工具容易被说成荐股或交易入口。

可观察结果：Agent 的研究回答包含数据时间，并拒绝买卖指令和实盘下单请求。

验收：

- 系统提示或护栏写明非投顾、不承诺收益。
- 请求下单时，工具列表里没有下单工具，回答说明拒绝原因。
- 输出中的价格和涨跌幅能追溯到一次网关调用。
- 安全测试不包含真实账户或可复用 Token。

非目标：不实现合规审查流程或面向客户的免责声明页面。

## REQ-005 研究跑分契约

问题：没有固定任务和独立裁判，自优化无法区分运气和改进。

可观察结果：同一组任务可以重复运行，并得到可比的分数和失败清单。

验收：

- 任务描述对执行器可见；评分标准在提议和探测阶段不可见。
- 分数不使用收益、夏普或涨停命中率。
- 一次运行记录任务标识、数据时间、`dsh` 版本、TSP 端点和分数。
- 至少有一条故意缺数的任务，确认失败不会换源补数。

非目标：不移植 JobBench、LAB 或 WorkBuddy-Bench。

## REQ-006 跑分自优化循环

问题：手改提示词不能说明哪次修改带来分数变化。

可观察结果：给定预算 `k`，循环对同一任务做提议、探测和组合，并保留执行对比。

验收：

- 执行会话使用 REQ-002 的 DeepSeek Harness 路径。
- 候选修改只落在提示、护栏、记忆、工具说明、子代理、技能、脚本和插件配置。
- 无效提议按契约重试有限次，然后继承当前 harness，不能中断整批任务。
- 探测阶段读不到裁判标准。
- 优化器不能改变 Token scope 或数据口径。

非目标：不保证分数上升。没有提升也是有效实验结果。

## REQ-007 只读研究会话

问题：在跑分之前，需要一条人能使用的最小研究路径，确认运行时和数据平面接得上。

可观察结果：研究者可以搜索标的、读取日 K 和市场环境，并看到每次工具调用。

验收：

- 只使用 `read:market` 与确认过的只读 scope。
- 不调用回测、扩展表写入或模拟盘。
- 回答列出数据时间和端点摘要。
- 面板不可达时，会话失败，不改用网页搜索充当行情。

非目标：不做选股策略生成，不做语音或推送。

## REQ-008 可复现实验记录

问题：自优化如果只在会话里发生，事后无法复核。

可观察结果：一次优化运行有独立目录，包含任务选择、候选 harness、执行证据、采纳结果和分数。

验收：

- 相同任务集、预算、模式和种子能定位到同一次记录。
- 记录不包含 Token 或模型密钥。
- 经验库条目要么有执行证据，要么不被后续任务读取。
- 报告命令只读记录，不重新调用模型。

非目标：不建立公开排行榜。
