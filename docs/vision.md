# 愿景

Sagebeast 要成为一个股票研究 Agent：研究者用自然语言提出问题，Agent 在可审计的工具调用里取数、解释口径、保留证据，并让承载这些行为的 harness 能按跑分结果自我改进。

它不替代行情终端，也不替代研究者做决定。

## 用户可观察的结果

接受相应需求并实现后，研究者应能：

1. 在 DeepSeek Harness 会话里提出研究问题。
2. 看到 Agent 只通过 tick-stock-panel 取数，并能展开每次调用的端点、时间和返回摘要。
3. 得到带数据时间的研究记录，而不是无来源的判断。
4. 用一组固定的研究任务给 Agent 跑分。
5. 让自优化循环根据执行证据改提示词、技能、工具说明或插件配置，再重新跑分，并留下可复现记录。

第 4 和第 5 项依赖跑分契约先被接受。在那之前，不实现优化循环。

## 非目标

- 不对标通用看盘软件。
- 不内置荐股、涨停预测或自动下单。
- 不自建行情数据源、复权引擎或指标库。
- 不把 Harness² 的法律、办公或职业基准当作本项目的分数。
- 不修改 DeepSeek Harness 上游来承载股票业务。

这些非目标来自产品边界，也来自上游自己的边界。tick-stock-panel 明确不做投顾和看盘对标；Harness² 优化的是固定权重模型外的 harness，而不是交易策略。
