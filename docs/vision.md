# 愿景

Sagebeast 是一个基本面研究 App。它学习 tick-stock-panel 的使用方式：页面负责看数据和策略，任意页面都能打开对话完成操作。对话的运行时是 DeepSeek Harness。

研究者应能把自己关心的股票写成可复用的基本面策略，让策略按集合并发运行，并在指定周期被叫醒后再次运行。策略通过对话编码产生，不是只存在于一次聊天里。

## 可观察的结果

需求被接受并实现后：

1. 打开 App 就能看到关心的标的、已保存策略和最近结果。
2. 在任意页面打开 DeepSeek Harness，创建或修改策略代码，分析数据，或继续普通对话。
3. 策略运行不依赖每个标的一个模型会话。失败的标的留在结果里。
4. 定时到期后，会话被叫醒并启动运行器。没开机就不会假装已经跑完。
5. 界面上的文字和图表在常见缩放下清楚。
6. 以后可以用固定的基本面任务给 harness 打分，并用 Harness² 的方法改进 `AGENTS.md`、skills 和工具说明。

第 6 项晚于能运行的策略。没有跑分契约时，不实现优化循环。

## 非目标

- 不把 tick-stock-panel 的技术面工作台原样搬过来。
- 不在面板没有契约时假装支持可转债和期货。
- 不内置荐股、涨停预测或实盘下单。
- 不训练模型权重。
- 不修改 DeepSeek Harness 或 tick-stock-panel 的核心来迁就本项目。
