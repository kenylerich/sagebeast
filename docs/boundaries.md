# 实现边界

这些边界在需求被接受后仍然有效。某条需求如果要求越过边界，先改本文件和对应决策记录，再实现。

## 运行时

- 不在本仓库维护 DeepSeek Harness 的 fork。
- 不复制 Agent 循环、工具注册表或会话日志。
- 对话里的编码只写 Sagebeast 的策略、技能和文档。不改上游核心，不改 tick-stock-panel 的内置策略目录。
- DeepSeek Harness 的定时只负责叫醒。它的回执不是策略运行完成。

## 数据

- 不直接调用数据源厂商，不读取面板的 Parquet、DuckDB 或 `data/`。
- 不在 Sagebeast 里重算复权、涨跌停或财务点时口径。
- 不把网页搜索的数字当成行情或财报。
- 面板没有契约的资产不发明字段。当前没有可转债和期货契约。

## 策略

- 策略必须是可登记的代码文件，不能只留在聊天记录里。
- 并发和长任务在运行器里完成。不为每个标的开一个模型会话来冒充并发。
- 技术面条件不能在财务字段缺失时悄悄替上。

## 自优化

- 不把 JobBench、LAB 或 WorkBuddy-Bench 的分数当作验收。
- 不把 Harness² 的 OpenCode 或 Codex 当作运行时。
- 提议阶段不能读取裁判标准。
- 优化器不能修改数据口径、Token scope 或运行器计算结果。

## 界面

- 不用整页缩放再拉伸 canvas 来放大界面。
- 不把背景模糊当作默认质感。

## 流程

- 未列入 `docs/decisions/0003-catalog-accepted.md` 的需求不能开工。
- 文档 PR 不能夹带可执行的产品实现。
